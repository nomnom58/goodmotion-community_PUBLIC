# Goodmotion 🪄

> Production-ready GSAP & Framer Motion components designed for modern web apps.

[![Live Demo]](https://goodmotion.vercel.app/))
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg?style=for-the-badge)](https://opensource.org/licenses/MIT)

Goodmotion is an open collection of curated, copy-paste interactive UI motion components and animation patterns built for Next.js, React, and Tailwind CSS developers.


https://github.com/user-attachments/assets/5d5ef733-84a6-431a-b55a-05724fa92eec


---

## ⚡️ Key Highlights

- **Copy-Paste Ready:** Drop directly into your Next.js and Tailwind projects.
- **GSAP & Framer Motion:** Fluid, performant micro-interactions and transitions.
- **Accessible & Responsive:** Tested across modern viewports and touch devices.
- **Zero Config Hassle:** Grab the snippet, paste into your codebase, and tweak parameters.

## 🛠 Tech Stack Integration

Goodmotion components are tailored for:

* **Framework:** Next.js (App Router), React
* **Styling:** Tailwind CSS
* **Animation Engines:** GSAP, Framer Motion
* **Type Safety:** TypeScript
